# TauCatch 真机硬件选型与验收表

更新：2026-10-28。用途：与部署同事、设备供应商沟通单球高速接球的硬件选型。

**建议候选为 FR3＋轻量可控机械手＋双目事件相机＋RGB相机。最终型号应由带载运动、闭合时间和整链路延迟实测决定。当前没有证明这套组合能够完成18m/s真机接球。**

## 1. 候选设备与推荐理由

下表“已确认参数”来自官方资料；推荐理由是针对本项目的工程判断，未验证项需要供应商或部署同事实测。

| 部件 | 候选及已确认参数 | 为什么考虑它 | 定型前必须确认 |
|---|---|---|---|
| 机械臂 | **Franka Research 3，含FCI**：7自由度、额定负载3kg、臂展855mm、关节力矩传感器。[官方参数](https://franka.de/franka-research-3) | 控制接口开放，便于实现快速跟踪、柔顺接触及VLA补偿 | 装上整套末端后的到达时间、动态误差、允许惯量与冲击条件 |
| 机械臂接口 | FCI/libfranka：1kHz控制与状态读取，提供关节及笛卡尔运动接口。[官方接口](https://frankarobotics.github.io/docs/doc/libfranka/docs/overview.html) | 能运行我们自己的快环并记录实际执行状态 | 交付版本、FCI使用条件、实时Linux及网络配置、SDK兼容性 |
| 机械手 | **Allegro Hand V5 Plus**：四指、16主动关节、约1.024kg、CAN通信500Hz、独立电流控制和指尖压力感知。[官方参数](https://www.allegrohand.com/sub/product/p.php?idx=4) | 支持预成形、包络抓取和接触后夹持调整，也方便后续扩展灵巧操作 | 实际球径下的有效闭合时间、抗反弹能力、触觉反馈更新率；官方500Hz通信不代表机械闭合速度 |
| 事件相机 | **2×DVXplorer或同级设备**：640×480，官方典型延迟＜1ms、时间分辨率200μs，支持多机同步。[官方资料](https://docs.inivation.com/hardware/current-products/dvxplorer.html) | 双目事件流用于快速运动跟踪和三维轨迹估计 | 安装基线、共同视野、标定误差、实际照明下的事件质量与交付延迟 |
| RGB相机 | **1×全局快门工业RGB相机**；例如Basler a2A1920-160ucBAS，默认164fps，支持硬件触发。[官方资料](https://docs.baslerweb.com/a2a1920-160ucbas) | 提供外观信息、VLA视觉输入及实验记录 | 镜头和曝光能否看清球；若飞行中更新，需要验证采集到可用图像的延迟 |
| RGB-D相机 | **可选辅助设备**，可优先评估现有设备 | 用于工作空间标定、静态几何和初始化 | 若深度参与飞行跟踪，必须另测高速运动下的深度误差与延迟；本方案的飞行三维跟踪主要依赖双目DVS |
| 计算与连接 | 实时控制PC＋GPU推理进程；专用控制网络、CAN接口、手电源、法兰及同步线缆 | 将运动控制与VLA推理解耦，避免推理阻塞控制周期 | 全负载下周期抖动、时钟对齐、数据日志；Allegro需要独立驱动，不能直接使用Franka原生夹爪API |

**FR3和Allegro均可替换。** 若已有满足实时接口、带载到达和有效闭合要求的设备，应优先评估现有设备。只做单球时，更轻、更快、带柔性包络的夹具也应纳入比较；V5 Plus的多指能力主要提供后续研究空间。

## 2. 必须先明确的任务边界

| 任务项 | 建议/定义 | 部署同事确认 |
|---|---|---|
| 球的规格 | 首阶段固定一种软球；记录直径、质量、摩擦和回弹特性 | 直径：____；质量：____；材料：____ |
| 速度范围 | 可先3–5m/s建立基线，再逐级评估8、12、18m/s；后续升级以实测为准 | 首阶段：____；最终目标：____ |
| 投球与观测位置 | 明确投球距离、相机首次可靠观测的位置 | 距离：____；可靠观测点：____ |
| 剩余可用时间 | 从首次可靠观测到球到达接球区域的时间 | 最短：____ms |
| 机械臂需要移动的范围 | 从指定初始手位，到接球位置和姿态；应包含末端偏置 | 最大移位：____cm；姿态变化：____ |
| 成功定义 | 接到指定球，并稳定保持至少0.5秒；分别记录无接触、反弹、滑脱 | 接球区域：____；允许误差：____ |

## 3. 选型硬条件与验收方法

“必须”是任务成立的条件；“设计目标”是当前方案的初步目标，需结合上表确认，并非行业标准或厂商保证。

| 项目 | 性质与要求 | 让供应商/部署同事提供什么 |
|---|---|---|
| 在线控制接口 | **必须**能持续更新命令和读取状态；本方案机械臂快环目标为1kHz | 实际可用控制模式、命令/反馈频率、周期抖动、丢包和命令生效延迟 |
| 带载到达能力 | **必须**在剩余时间内到达接球位置及姿态，并保留闭合与控制余量 | 安装真实手、法兰、传感器及线缆后，指定运动的最短到达时间、跟踪误差和可重复性 |
| 质量、重心与惯量 | **必须**满足机械臂动态负载条件；仅“总质量低于3kg”不足以判断 | 整套末端质量、重心、惯量及厂家认可的运行范围 |
| 手的有效闭合 | **必须**从预成形姿态及时形成对目标球的包络 | 给定球径、开口和姿态的闭合时间分布；说明是接触前预闭合还是接触后闭合 |
| 接触与保持 | **必须**在约定球速/球质量下保持0.5秒 | 接触后的反弹、滑脱、夹持力、掌心缓冲表现及允许冲击条件 |
| 双目事件视觉 | **必须**输出可标定、可对齐时间的原始事件 | 真实距离、照明和球速下的三维轨迹误差、丢事件、采集到交付的延迟 |
| 时间同步 | 设备时基对齐误差先以**0.1–0.2ms量级作为设计目标**，需实测 | 相机间同步误差、相机与机器人时钟映射方法；不能用USB到包时刻替代采样时间 |
| RGB图像 | 释放前外观输入优先保证清晰；飞行中使用时需短曝光、低延迟，全局快门优先 | 对应镜头、曝光、帧率及完整图像交付延迟，不能只报最高帧率 |
| 整链路时延 | **必须**满足任务截止时间，快环不能等待VLA返回才继续控制 | 分开记录采集、处理、推理、通信、执行生效的P95/P99延迟和动作过期率；6ms网络推理不能代替整链路测量 |
| 驱动与配套 | **必须**具备可用SDK、驱动及完整机械/电气连接 | 软件版本、CAN与电源方案、法兰、线缆布置、模型文件和标定流程；V5 Plus官方电源规格为24V/5A。[手的官方规格](https://www.allegrohand.com/sub/product/p.php?idx=4) |

时间同步目标的依据是：18m/s时，**1ms未补偿的时间偏差对应1.8cm沿轨迹位移**。预测可以补偿已知延迟，但未知时钟偏差仍会影响定位与控制。

## 4. 为什么不能只看最大速度

| 容易混淆的参数 | 对本项目的实际含义 |
|---|---|
| 球速18m/s | 机械臂要提前到达拦截位置，不要求机械臂也达到18m/s；关键是剩余时间内的移位和姿态变化 |
| 机械臂最大速度 | 接球运动往往很短，可能尚未加速到最大速度就需要减速；带载加速度、关节姿态和轨迹平滑约束同样关键 |
| CAN通信500Hz | 表示通信更新能力，不能推出手的有效闭合时间 |
| 事件相机标称＜1ms | 是传感器典型参数，不能直接视为事件处理、三维估计和控制生效的总延迟 |

简单下界：静止出发、直线移动距离`d`后停下，理想对称加减速需要`a_min = 4d/T²`。移动10cm、200ms完成，需要10m/s²；当前FR3接口文档列出的平移加速度上限为9m/s²、速度上限为3m/s，实际还受关节、姿态及负载等限制。因此，若该运动要求是硬条件，FR3就需要被重新评估。[FR3官方运动限制](https://frankarobotics.github.io/docs/robot_specifications.html)

**当前仿真也不能直接当作FR3真机能力。** 项目使用`agile`理想化机械臂，以及轻量、快速的理想化手；选型后必须按真实速度、加速度、惯量和闭合时间重建仿真。[当前仿真配置](../taucatch/scene.py)

## 5. 建议的部署与验证顺序

| 阶段 | 具体工作 | 进入下一阶段的依据 |
|---|---|---|
| ① 带载与标定 | 安装完整末端；测到达/闭合时间、相机外参和时钟误差；更新真实约束模型 | 任务的时间预算与运动范围可实现 |
| ② 单球快环基线 | 固定球型和小范围，先低速；实现DVS跟踪、拦截、预成形及保持 | 取得可重复的接稳基线，能区分感知、到达、闭合和滑脱问题 |
| ③ 加入SpikeVLA | 在真实约束仿真中学习补偿，再小规模适配真机；用相同速度/范围交替比较VLA开与关 | VLA接稳率或鲁棒性有可验证提升，再扩大速度和接球范围 |

采购前最有价值的证明是：**同一任务定义下，完整带载设备的实测轨迹、有效闭合时间和整链路时间记录。** 型号、自由度和宣传参数用于筛选，最终由这些结果决定。
